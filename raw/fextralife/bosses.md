# Path of Exile 2 Bosses

## Overview

Path of Exile 2 features "over 100 Bosses" with unique designs and attack patterns. The game includes powerful enemies serving as gatekeepers throughout the campaign, each with distinct mechanics and arena designs.

Players will find a boss in each zone. Some of them are optional, while others are part of the campaign requiring them to be eliminated before players can progress the story.

## Boss Fight Mechanics

### Core Mechanics
- **Circular Arenas**: All boss fights occur in circular-shaped battle spaces
- **Checkpoints**: Players can return to checkpoints before boss encounters if defeated
- **No Death Penalty**: Unlike the original game, "NO DEATH PENALTY. POE 1 used to impose an experience loss each time a player dies, but Path of Exile 2 will no longer have this mechanic"
- **Health Reset**: Defeated players face full boss health restoration upon respawn
- **Crowd Control**: Freeze, Stun, and Immobilize effects work against bosses but build resistance after application

### Crowd Control System
Effects accumulate over time and eventually trigger. Both players and enemies gain temporary CC resistance post-application.
