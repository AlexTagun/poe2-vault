# Uncut Skill Gems

Uncut Skill Gems are raw items needed to craft Skill Gems through the Gemcutting mechanic. Players engrave them to create the desired Skill Gems.

## Types
- Uncut Skill Gem – creates active combat skills
- Uncut Support Gem – enhances Skill Gems with additional effects
- Uncut Spirit Gem – third gem category

## Acquisition
Usually found as drops from defeating relatively greater enemies. Cannot be looted directly as finished gems — must be engraved at the Gemcutting interface.

## Notes
- Provides choice without requiring specific drops
- Collected for building diverse skill pool
- Used for leveling active Skill Gems
- Wiki note (Jan 2025): list of Level 3 Uncut Gems reportedly incomplete in source
