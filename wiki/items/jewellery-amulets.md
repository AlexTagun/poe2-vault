# Амулеты

Амулеты — тип [[items/jewellery|украшений]] в PoE 2. Дают разнообразные бонусы: сопротивления стихиям, жизнь и ману, бонусы к атрибутам или специфическим навыкам. Можно надеть **только один** амулет.

## Базовые типы

| Название | Имплицитный модификатор |
|----------|------------------------|
| Crimson Amulet | (2–4) регенерации жизни в секунду |
| Azure Amulet | (20–30)% повышенная скорость регенерации маны |
| Amber Amulet | +(10–15) к Силе |
| Jade Amulet | +(10–15) к Ловкости |
| Lapis Amulet | +(10–15) к Интеллекту |
| Lunar Amulet | +(20–30) к максимальному Щиту энергии |
| Bloodstone Amulet | +(30–40) к максимальному запасу жизни |
| Stellar Amulet | +(5–7) ко всем атрибутам |
| Solar Amulet | +(10–15) к Духу |
| Gold Amulet | (12–20)% повышенная редкость найденных предметов |

## Заметки

- Базовые типы не имеют требований к атрибутам или уровню
- Выбор амулета сильно влияет на приоритеты атрибутов персонажа
- [[Solar Amulet]] — единственный базовый тип с бонусом к [[Spirit|Духу]]
- Уникальные амулеты могут кардинально менять стиль игры (например, [[Astramentis]] для attribute-stacking билдов)
