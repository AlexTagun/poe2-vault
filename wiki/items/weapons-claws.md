# Claws

Когти — быстрое одноручное оружие DEX. Самый высокий APS среди всех видов оружия. Встроенная поддержка лича жизни и маны — ключевая механика выживаемости для атак-скиллов.

Связанные: [[items/weapons|Weapons]] · [[items/unique-weapons|Unique Weapons]]

## Характеристики

- **Атрибуты:** DEX
- **Тип:** 1H
- **Дальность:** 1.1
- **Крит:** 5% (базовый), 6.5% у Piercing Claw
- **APS:** 1.55–1.70 — самые быстрые ближнебойные базы

## Замечания

- **Wolfbone Claw** — встроенный «Life per Hit» делает её отличной стартовой базой для leeching-сборок.
- **Edged Claw** — blind on hit из имплицита хорошо работает с атакующими скиллами, требующими точности.
- Высокий APS когтей сочетается с суффиксом **Leeches % as Life/Mana** — частые удары компенсируют низкий урон за хит.
- Можно использовать два когтя одновременно (dual-wield).
