# Самоцветы (Jewels)

Самоцветы — особые предметы, вставляемые в сокеты [[mechanics/passive-skill-tree|Дерева пассивок]]. Часть самоцветов изменяет поведение пассивных навыков в радиусе вокруг себя.

## Обычные самоцветы

| Название | Примечание |
|----------|------------|
| Timeless Jewel | Изменяет пассивки в радиусе; особая механика «timeless» |
| Emerald | Стандартный — ориентирован на Ловкость |
| Diamond | Стандартный — ориентирован на Интеллект / нейтральный |
| Ruby | Стандартный — ориентирован на Силу |
| Sapphire | Стандартный — ориентирован на Интеллект |

## Time-Lost самоцветы

| Название | Радиус |
|----------|--------|
| Time-Lost Emerald | 1000 |
| Time-Lost Diamond | 1300 |
| Time-Lost Ruby | 1000 |
| Time-Lost Sapphire | 1000 |

Time-Lost варианты имеют больший радиус и затрагивают больше пассивных узлов.

## Уникальные самоцветы

| Название | База |
|----------|------|
| Heroic Tragedy | Timeless Jewel |
| Grand Spectrum | Emerald / Ruby / Sapphire |
| From Nothing | Diamond |
| Prism of Belief | Diamond |
| Against the Darkness | Time-Lost Diamond |
| Controlled Metamorphosis | Diamond |
| The Adorned | Diamond |

## Механики

- **Grand Spectrum** — бонус усиливается при вставке нескольких копий (set-бонус)
- **Timeless Jewel** — кардинально меняет пассивки в радиусе; требует изучения конкретных эффектов
- Самоцветы Magic/Rare роллят аффиксы как обычные предметы
- Самоцветы вставляются в Дерево пассивок, а **не** в экипировку
