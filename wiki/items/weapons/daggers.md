# Daggers

Кинжалы — быстрое одноручное оружие DEX+INT с очень высоким базовым критом (13.5–15%). Основа для крит-стайкинговых и спелл-атакующих сборок.

Связанные: [[items/weapons/weapons|Weapons]] · [[items/weapons/uniques|Unique Weapons]]

## Характеристики

- **Атрибуты:** DEX + INT
- **Тип:** 1H
- **Дальность:** 1.0 (самая низкая среди ближнего боя)
- **Крит:** 13.5–15% — наибольший среди всех видов оружия
- **APS:** 1.0–1.65

## Замечания

- **Ethereal Blade** — исключение: крит всего 6%, вероятно специальная база.
- **Moon Dagger** — 100% конверсия в холод из имплицита; полезно для холодного крит-билда.
- **Bloodletting Dagger** — конвертирует ману заклинаний в жизнь; редкий имплицит для Blood Mage ([[builds/ascendancies/blood-mage|Blood Mage]]).
- **Mail Breaker** — низкий APS (1.0), но разрушает броню при крите; для пробития сильнобронированных врагов.
- Кинжалы можно использовать в dual-wield.
