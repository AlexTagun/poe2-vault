# Body Armour

Нагрудная броня — самый весомый слот защиты. Поддерживает **до 2 сокетов**.

## Типы защиты

| Тип | Защита | Атрибуты |
|-----|--------|----------|
| Pure Armour | только Armor | Strength |
| Pure Evasion | только Evasion | Dexterity |
| Pure Energy Shield | только ES | Intelligence |
| Armour/Evasion | гибрид | Str + Dex |
| Armour/Energy Shield | гибрид | Str + Int |
| Evasion/Energy Shield | гибрид | Dex + Int |
| Tri-stat | все три | Str + Dex + Int |

## Особые базы

**Golden Mantle** (Lvl 20, 8 Str/8 Dex/8 Int) — трёхстатный гибрид с имплиситом на все стихийные резисты. Уникален среди ранних баз.

**Grand Regalia** (Lvl 65, 51 Str/51 Dex/51 Int) — эндгейм трёхстатный, Armor 135 / Evasion 123 / ES 46, без имплисита.

## Тиры баз (тезисно)

- **Base** — уровни 1–58, покрывают всю прогрессию до эндгейма
- **Advanced** (префикс "Advanced") — уровни 45–65
- **Expert** (префикс "Expert") — уровни 65–80, лучшие имплиситы
