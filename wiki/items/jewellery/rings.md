# Кольца

Кольца — тип [[items/jewellery/jewellery|украшений]] в PoE 2. Дают разнообразные бонусы: атрибуты, сопротивления, специфические усиления. Можно надеть **два** кольца одновременно.

## Базовые типы

| Название | Имплицитный модификатор |
|----------|------------------------|
| Golden Hoop | +(8–12) ко всем атрибутам |
| Iron Ring | Добавляет 1–4 физического урона к атакам |
| Lazuli Ring | +(20–30) к максимальной мане |
| Ruby Ring | +(20–30)% к сопротивлению огню |
| Sapphire Ring | +(20–30)% к сопротивлению холоду |
| Topaz Ring | +(20–30)% к сопротивлению молнии |
| Amethyst Ring | +(7–13)% к сопротивлению хаосу |
| Emerald Ring | +(120–160) к рейтингу точности |
| Pearl Ring | (7–10)% повышенная скорость чтения заклинаний |
| Prismatic Ring | +(7–10)% ко всем стихийным сопротивлениям |
| Gold Ring | (6–15)% повышенная редкость найденных предметов |
| Unset Ring | Предоставляет 1 дополнительный слот навыка |

## Заметки

- Базовые типы не имеют требований к атрибутам или уровню
- [[Unset Ring]] уникален тем, что даёт дополнительный слот навыка — ценен для билдов, которым нужны дополнительные активные навыки
- Кольца сопротивлений (Ruby/Sapphire/Topaz/Amethyst/Prismatic) — стандартный способ добрать до капа сопротивлений
- [[Iron Ring]] — единственное кольцо с наступательным уроном (физический бонус к атакам)
- [[Pearl Ring]] даёт Cast Speed — актуально для кастеров
