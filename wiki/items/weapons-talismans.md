# Talismans

Талисманы — эксклюзивное оружие **Друида** (Druid). Позволяют использовать **Shapeshifting**: превращение в Bear, Werewolf или Wyvern. Требуют STR+INT.

Связанные: [[items/weapons|Weapons]] · [[builds/ascendancies/shaman|Shaman]] · [[builds/ascendancies/oracle|Oracle]]

## Характеристики

- **Атрибуты:** STR + INT
- **Тип:** 1H (предположительно, исходя из дальности 1.2)
- **Дальность:** 1.2
- **Крит:** 5–11%
- **APS:** 1.1–1.45
- **Только для:** Druid

## Shapeshifting

Талисман активирует трансформацию Друида. Форм три:
- **Bear** — высокая выносливость, физический урон.
- **Werewolf** — скорость, урон в движении.
- **Wyvern** — воздушная мобильность, атаки сверху.

Переключение форм возможно **в бою** без задержки.

## Замечания

- **Jade Talisman** — наивысший физический урон (101–151), но низкий APS и крит; база для «медведя-танка».
- **Thunder Talisman** — огромный разброс урона (23–131 — аномальный минимум); имплицит шока.
- **Wingbeat Talisman** — самый высокий APS (1.45) среди талисманов; тематично для Wyvern-формы.
- **Ashbark/Cinderbark** — усиление Flammability; огненные шаман-сборки.
- **Rage** серия (Condemned, Fury, Maji, Rabid, Roaring) — Maximum Rage увеличивает потолок для rage-механик Шамана.
