# Gemcutting — Fextralife Wiki

## Overview

Gemcutting refers to the ingredients needed to create Skill Gems, Support Gems, or Buff Skill Gems, by engraving Uncut Skill Gems into usable gems through a dedicated interface menu.

Players acquire Uncut Gems throughout gameplay and refine them using the Gemcutting interface rather than finding completed Skill Gems directly. This system enables crafting up to 9 preferred Skill Gems and creating modifiers for playstyle customization.

## Gem Types

- **Skill Gems**: Grant combat abilities as primary offensive or defensive actions
- **Support Gems**: Enhance functionality of Active Skills without granting new abilities
- **Persistent Buff Skill Gems**: Provide permanent or temporary enhancements to character, allies, or minions
- **Meta Gems**: Advanced gems triggering effects under specific conditions

## Equipment System

"Gear no longer contains sockets for Skill Gems. Instead, Skill Gems are equipped directly by your character, with up to nine active skills available."

Each Skill Gem can be enhanced by up to five Support Gems. Skills are assigned to a Skill Bar located near the Mana Orb.

## Support Gem Mechanics

Each Support Gem linked increases associated Attribute requirements by +5. For example, linking Multiple Projectiles to Fireball raises Dexterity requirements by 5 points.

"You cannot use the same Support Gem, such as Multiple Projectiles, on two different skills."

## Gem Tags

Tags define properties and interactions — determining which Support Gems can link and how skills scale with stats and Passive Skills.
