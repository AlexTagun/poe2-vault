# Пояса

Пояса — тип [[items/jewellery|украшений]] в PoE 2. Дают утилитарные и защитные бонусы, в основном связанные с эффективностью [[Flask|фласков]], управлением [[Charm|чарами]] и выживаемостью. Можно надеть **один** пояс.

## Базовые типы

| Название | Имплицитный модификатор |
|----------|------------------------|
| Golden Obi | (20–30)% повышенная редкость найденных предметов |
| Rawhide Belt | (20–30)% повышенное восстановление жизни от фласков |
| Linen Belt | (20–30)% повышенное восстановление маны от фласков |
| Wide Belt | (20–30)% повышенное накопление зарядов фласка |
| Long Belt | (15–20)% увеличенная длительность эффекта чар |
| Plate Belt | +(100–140) к броне |
| Ornate Belt | (10–15)% уменьшенный расход зарядов чар |
| Mail Belt | (10–15)% уменьшенный расход зарядов фласка |
| Double Belt | (20–30)% повышенное накопление зарядов чар |
| Heavy Belt | (20–30)% повышенный порог оглушения |
| Utility Belt | 20% восстановления от фласка применяется мгновенно |
| Fine Belt | Фласки накапливают 0.17 заряда в секунду |

## Заметки

- Базовые типы не имеют требований к атрибутам или уровню
- Большинство поясов взаимодействуют с системами [[Flask]] и [[Charm]] — выбор пояса существенно влияет на устойчивость
- [[Plate Belt]] — единственный пояс с прямым защитным статом (броня)
- [[Heavy Belt]] с порогом оглушения ценен для танкоустойчивых билдов
- [[Utility Belt]] с мгновенным восстановлением от фласка полезен для экстренного хила
