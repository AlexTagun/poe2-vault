# Belts

Belts are a type of Jewellery in Path of Exile 2. They provide various utility and defensive bonuses, mostly centered around flask efficiency, charm management, and survivability stats.

## All Belts

| Name | Implicit Mod |
|------|-------------|
| Golden Obi | (20–30)% increased Rarity of Items Found |
| Rawhide Belt | (20–30)% increased Life Recovery from Flasks |
| Linen Belt | (20–30)% increased Mana Recovery from Flasks |
| Wide Belt | (20–30)% increased Flask Charges gained |
| Long Belt | (15–20)% increased Charm Effect Duration |
| Plate Belt | +(100–140) to Armour |
| Ornate Belt | (10–15)% reduced Charm Charges used |
| Mail Belt | (10–15)% reduced Flask Charges used |
| Double Belt | (20–30)% increased Charm Charges gained |
| Heavy Belt | (20–30)% increased Stun Threshold |
| Utility Belt | 20% of Flask Recovery applied Instantly |
| Fine Belt | Flasks gain 0.17 charges per second |

## Notes

- No attribute requirements or level requirements listed on base types
- Many belts interact with Flask and Charm systems — belt choice can significantly affect sustain
- Plate Belt is the only belt providing a direct defensive stat (Armour)
- Heavy Belt's stun threshold is valuable for tankier builds
- Utility Belt's instant flask recovery is useful for burst healing scenarios
- Headhunter (unique Heavy Belt) is one of the most iconic items in the game
