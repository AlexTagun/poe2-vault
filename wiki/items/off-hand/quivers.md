# Quivers

Колчаны — [[items/off-hand/off-hand|off-hand]] экипировка исключительно для луков ([[Bows]]). Каждый тип даёт уникальный implicit-модификатор для атак.

## Ключевые свойства

- Только для персонажей с луком
- Нет атрибутных требований (кроме уровня)
- Нет защитных статистик (броня, уворот, ES, блок)
- Каждый тип имеет один чёткий игровой фокус

## Все Quivers

| Название | Implicit | Уровень |
|----------|----------|---------|
| Broadhead Quiver | Adds 1 to 3 Physical Damage to Attacks | — |
| Fire Quiver | Adds 3 to 5 Fire Damage to Attacks | 8 |
| Sacral Quiver | Gain (2–3) Life per Enemy Hit with Attacks | 16 |
| Two-Point Quiver | (20–30)% increased Accuracy Rating | 24 |
| Blunt Quiver | (20–30)% reduced Enemy Stun Threshold | 33 |
| Toxic Quiver | (10–15)% chance to Poison on Hit with Attacks | 39 |
| Serrated Quiver | Attacks have (10–15)% chance to cause Bleeding | 44 |
| Primed Quiver | (7–10)% increased Attack Speed | 51 |
| Penetrating Quiver | 100% chance to Pierce an Enemy | 55 |
| Volant Quiver | (20–30)% increased Arrow Speed | 61 |
| Visceral Quiver | (20–30)% increased Critical Hit Chance for Attacks | 65 |

## Выбор колчана по стилю игры

| Стиль | Рекомендуемый колчан |
|-------|---------------------|
| Physical / Scaling | Broadhead Quiver |
| Fire / Elemental | Fire Quiver |
| Poison / DoT | Toxic Quiver |
| Bleed | Serrated Quiver |
| Fast Attack | Primed Quiver |
| Pierce builds | Penetrating Quiver |
| Crit | Visceral Quiver |
| Projectile speed / Chain | Volant Quiver |
| Stun | Blunt Quiver |
| Sustain | Sacral Quiver |
