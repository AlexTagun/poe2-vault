# Shields

Shields are a type of Off-Hand Equipment in Path of Exile 2. They emphasize blocking mechanics to reduce incoming damage and are an essential choice for builds that prioritize defense.

## Shield Types

| Type | Defense Focus | Move Speed Penalty | Attribute |
|------|--------------|-------------------|-----------|
| Tower Shields | Armor only | -3% | Strength |
| Targes / Crest Shields | Armor + Evasion or Armor + ES | -1.5% | Str + Dex or Str + Int |
| Bucklers | Evasion only | None | Dexterity |

## Notes

- All shields grant access to the **Raise Shield** skill (except bucklers and Golden Flame)
- Tower Shields: pure Strength requirement, highest armor, -3% move speed
- Targes: Strength + Dexterity, armor/evasion hybrid, -1.5% move speed
- Crest Shields: Strength + Intelligence, armor/energy shield hybrid, -1.5% move speed
- Bucklers: pure Dexterity, pure evasion, no move speed penalty
- Expert tier shields have increased move speed penalty (-3%) compared to standard/advanced (-1.5%) for non-Tower types
