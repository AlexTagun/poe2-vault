# Body Armour

Body Armour is essential for defense in Path of Exile 2, offering benefits like reducing physical damage, increasing the chance to avoid attacks, and providing extra protection against spells. Supports up to 2 sockets.

## Defense Types

| Type | Defense | Attribute |
|------|---------|-----------|
| Pure Armour | Armor only | Strength |
| Pure Evasion | Evasion only | Dexterity |
| Pure Energy Shield | ES only | Intelligence |
| Armour/Evasion | Hybrid | Str + Dex |
| Armour/Energy Shield | Hybrid | Str + Int |
| Evasion/Energy Shield | Hybrid | Dex + Int |
| All three | Tri-stat | Str + Dex + Int |
