# Soul Cores

Soul Cores — мощные socketable предметы с уникальными модами, недоступными через обычные [[runes|руны]]. Происходят из Хаоса, реплицированы Вал через кровавую магию. Получить можно через Trialmaster.

Связанные темы: [[crafting/crafting-overview|crafting-overview]], [[mechanics/atlas-endgame|atlas-endgame]]

## Механика

Вставляются в сокеты оружия или брони так же как [[runes|руны]]. Дают уникальные эффекты, которые нельзя получить через стандартный крафт. Каждый Core имеет разные эффекты для оружия и брони.

## Советы

- Requirement-конвертеры (Atmohua, Zantipi, Cholotl) полезны для мультиатрибутных билдов
- Charge cores (Opiloti, Guatelitzi, Xopec) незаменимы для charge-based билдов
- Армор-трио (Heatproofing, Dampening, Insulation) — для Armour-стаггера против элементальных хитов
