# Weapons

Основной хаб по оружию в Path of Exile 2. Оружие — главный источник урона и определяет доступные скиллы и стиль игры.

## Категории оружия

### Ближний бой — STR
- [[items/weapons/maces|Maces]] (1H/2H) — STR. Stunbuildup, слом защиты.
- [[items/weapons/flails|Flails]] (1H) — STR+INT. Радиальные удары с элементальными эффектами.

### Ближний бой — STR+DEX
- [[items/weapons/axes|Axes]] (1H/2H) — STR+DEX. Баланс силы и скорости.
- [[items/weapons/swords|Swords]] (1H/2H) — STR+DEX. Универсальность.
- [[items/weapons/spears|Spears]] (2H) — STR+DEX. Дальность удара 1.5, броски.

### Ближний бой — DEX
- [[items/weapons/claws|Claws]] (1H) — DEX. Высокий APS, лич/мана-лич.
- [[items/weapons/daggers|Daggers]] (1H) — DEX+INT. Крит 13.5–15%, цисы.

### Ближний бой — DEX+INT
- [[items/weapons/quarterstaves|Quarterstaves]] (2H) — DEX+INT. Крит 10–11.5%, блок на некоторых базах.

### Дальний бой
- [[items/weapons/bows|Bows]] (2H) — DEX. Дополнительные стрелы в имплицитах.
- [[items/weapons/crossbows|Crossbows]] (2H) — STR+DEX. Механика перезарядки (Reload Time).

### Магические
- [[items/weapons/wands|Wands]] (1H) — INT. Встроенный скилл-гем, спелл-дамаг.
- [[items/weapons/staves|Staves]] (2H) — INT. Встроенный скилл-гем, +уровни заклинаний.
- [[items/weapons/sceptres|Sceptres]] (1H) — STR+INT. Даёт Spirit + встроенный скилл-гем, баффы миньонам.

### Специфические
- [[items/weapons/talismans|Talismans]] (1H) — STR+INT. **Только для Друида.** Включает Shapeshifting (Bear/Werewolf/Wyvern).
- [[items/weapons/traps|Traps]] — DEX+INT. Ловушки: ручная активация или по proximity.

### Уникальные
- [[items/weapons/uniques|Unique Weapons]] — все уникальные образцы по типу оружия.

## Ключевые механики

### Gem Sockets
Сокеты на оружии **не нужны** для Skill Gems (изменение по сравнению с PoE 1) — гемы вставляются в отдельные слоты.  
Сокеты используются для **Ezomyte Runes** (через [[Artificer's Orb]]):
- Одноручное оружие — до **1** сокета.
- Двуручное оружие — до **2** сокетов.

### Weapon Swap (Смена оружия)
Два активных сета оружия; переключение — клавиша **X** (клавиатура) или радиальное меню (геймпад).  
Каждый скилл можно привязать к конкретному сету — смена произойдёт автоматически при активации.

### Dual Specialization (Двойная специализация)
Пассивное дерево поддерживает разные аллокации для двух сетов:
- Красные ноды — Set I.
- Зелёные ноды — Set II.

Подробнее: [[mechanics/passive-skill-tree]].

## Редкости предметов

| Редкость | Особенность |
|----------|-------------|
| Normal | Без модов |
| Magic | 1–2 мода (через Orb of Transmutation/Augmentation) |
| Rare | 3–6 модов (через Regal Orb / Exalted Orb) |
| Unique | Фиксированные уникальные модификаторы |

## Крафт-валюты

| Валюта | Действие |
|--------|----------|
| Orb of Transmutation | Normal → Magic |
| Orb of Augmentation | Добавить мод к Magic |
| Regal Orb | Magic → Rare |
| Exalted Orb | Добавить мод к Rare |
| Artificer's Orb | Добавить сокет (Ezomyte Rune) |
