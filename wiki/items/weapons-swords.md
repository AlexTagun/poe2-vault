# Swords

Мечи — универсальное оружие STR+DEX, поддерживающее широкий спектр стилей боя. Доступны одноручные и двуручные варианты.

Связанные: [[items/weapons|Weapons]] · [[items/unique-weapons|Unique Weapons]]

## Характеристики

- **Атрибуты:** STR + DEX
- **Тип:** 1H (данные на момент снапшота); 2H базы не были представлены на странице вики
- **Дальность:** 1.1
- **Крит:** 5%
- **APS:** 1.1–1.70

## Аффиксы

## Замечания

- **Energy Blade** (в списке как Ethereal Blade) — 0 физ. урона; весь урон приходит из имплицита **Adds Lightning Damage**; для молниевых атак.
- **Golden Blade** — редкий имплицит **+(16–24) to all Attributes**; полезна для выравнивания требований к атрибутам.
- **Vampiric Blade** — из названия предполагает лич-механику, но конкретный имплицит в источнике не указан.
- Мечи — гибкая основа для STR/DEX-персонажей; хорошо подходят для [[builds/ascendancies/deadeye|Deadeye]] при dual-wield и для меле-сборок Рейнджера.
- 2H мечи на момент снапшота не были отображены на странице вики.
